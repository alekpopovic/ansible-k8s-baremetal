# containerd

Installs and configures containerd as the Kubernetes container runtime.

The default implementation installs containerd from the operating system
package manager. A future `containerd_install_source` value can add support for
Docker/containerd upstream apt repositories, but only the OS package path is
implemented now.

## What It Does

- Installs the containerd package.
- Creates `/etc/containerd`.
- Generates `/etc/containerd/config.toml` from `containerd config default` only
  when the file is missing.
- Sets `SystemdCgroup = true` for Kubernetes kubelet/containerd alignment.
- Optionally overrides the configured pause image.
- Enables and starts the containerd service.
- Restarts containerd only when the configuration changes.
- Validates `containerd --version`.
- Validates `systemctl is-active containerd`.

## Variables

```yaml
containerd_enabled: true
containerd_install_source: os
containerd_package_name: containerd
containerd_service_name: containerd
containerd_config_dir: /etc/containerd
containerd_config_file: /etc/containerd/config.toml
containerd_pause_image: ""
```

Set `containerd_pause_image` only when the default generated by containerd
should be overridden:

```yaml
containerd_pause_image: "registry.k8s.io/pause:3.10"
```

When `containerd_pause_image` is empty, this role does not hardcode or modify
the sandbox image value.
